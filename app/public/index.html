Practice Pages

This local app is the "system under test" for the Playwright framework. Each page demonstrates an industry-standard UI pattern you can write tests against.

  • Login — form validation & auth errors
  • Inventory — API-backed product grid, sorting, add/remove to cart (requires login)
  • Cart — cart contents & removal (requires login)
  • Data Table — sorting, filtering, pagination
  • Forms — required fields, email format, inline errors
  • Dynamic Loading — spinner then async content
  • Modal Dialog — open/close, focus, confirm
  • File Upload — choose a file and upload
